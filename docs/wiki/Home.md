# fjgo manual

`fjgo` is a lightweight Go CLI that helps coding agents work safely with
Forgejo repositories and APIs.

Use normal `git` commands for commits, branches, and local files. Use `fjgo`
for work that needs the Forgejo server: issues, pull requests, releases,
Actions, repository settings, and the wider Forgejo API.

The public npm launcher is `@astrazds/fjgo`. The command name remains `fjgo`.

Start with [Getting Started](Getting-Started).
